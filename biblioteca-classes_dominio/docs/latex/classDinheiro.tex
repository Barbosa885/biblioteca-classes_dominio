\doxysubsection{Detailed Description}
Classe responsável pela representação de uma quantia em dinheiro. 

Esta classe encapsula a lógica relacionada ao gerenciamento de quantias em dinheiro, incluindo a validação do valor e a manipulação de seus componentes.
