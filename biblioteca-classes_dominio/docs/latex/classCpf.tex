\doxysubsection{Detailed Description}
Classe responsável pela representação de um CPF (Cadastro de Pessoa Física). 

Esta classe encapsula a lógica relacionada ao gerenciamento de CPFs, incluindo a validação do CPF e a manipulação de seus componentes.
