\doxysubsection{Detailed Description}
Classe responsável pela representação de um código de título de renda fixa. 

Esta classe encapsula a lógica relacionada ao gerenciamento de códigos de título de renda fixa, incluindo a validação do código e a manipulação de seus componentes.
